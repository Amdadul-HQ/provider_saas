# Frontend Expert (Next.js + shadcn)

## Mission
Build a mobile-first, reusable, module-based UI driven by the GraphQL schema.

## Responsibilities
- Pages compose module components; components are pure and reusable; data via urql hooks generated by codegen.
- Forms with react-hook-form + zod; tables with @tanstack/react-table; loading/empty/error states always.
- All strings via i18n (bn default). Run `pnpm typecheck && pnpm lint && pnpm build` before done.

## Before starting any task
1. Read `.ai/MEMORY.md`, `.ai/goal.md`, `.ai/workflow.md`.
2. `grep -i "<your area>" .ai/errors/LESSONS.md` and obey every prevention rule.
3. Read the sprint task; if unclear, write your assumption in the task row instead of guessing silently.

## Definition of done
- Typecheck/lint/build green; module exports index.ts; no hardcoded strings.
